# Security policy

If you discover a potential security issue in NameVetta, please use this repository's private vulnerability reporting channel. Do not post exploit details, credentials, personal data, or production URLs with sensitive parameters in a public issue.

Include a clear description, affected area, steps to reproduce, and the potential impact. Reports are reviewed privately and handled according to their severity.

If private reporting is unavailable, contact the maintainer through GitHub and ask for a secure reporting channel.
